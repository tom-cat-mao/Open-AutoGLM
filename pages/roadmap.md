# 路线图

## 已完成

- **thin-loop v2 主体**：工具环替代图编排（v1 LangGraph 架构已删除）
- **原子观测生命周期**：单生产者 + epoch 批次徽章 + 新鲜度闸门
- **安全预警制**（wary 默认）+ finish 两段式 + 独立验收器
- **Token 预算 + 两级 auto-compact**
- **App-KB**：设备事实 + learned/user 别名 + dream 整理 + 隐式纠正
- **locate 升级**：原图直给 + hint-first + 可选 scope 裁剪（容器/锚点区间）
- **Web 控制台**：实时监看、步骤详情、截图历史、软停止、每轮配置覆盖、App-KB 页
- **统一 UsageLedger**：旁路模型调用全部计入预算

## 进行中

- **经验数据面**：episode 记录（隐私白名单）+ UsageLedger 持久化 + dream 经验维护
- **语义回想（RAG shadow）**：sqlite-vec + 本地 MLX 嵌入；影子模式自验证命中率，达标前不注入

## 下一步

- **能力注册表（插件化内核）**：每个能力可关、可版本化、可单独回滚；依赖缺失可见待岗；每 run 的"激活能力+记忆代际"可审计
- **控制台记忆页**：episode 流、回想命中率、能力状态可视化

## 再往后（数据达标才开工）

- **经验提炼与晋升**：dream v2（LLM 对照蒸馏）→ Rule-of-3 → 人审 → 有界注入（3+1 条 / 800 token）→ 版本化撤销
- **Context 高收益档**：prefix-cache 动静块排序（需 P0 评审）、compact 摘要携带记忆状态
- **程序性记忆**：workflow 套路（白名单、前后置条件完备的可逆流程）
- **强弱模型路由**：按任务复杂度分流，省钱
