# Web 控制台

本地 Web 控制台（NiceGUI）用于实时监看与操控。启动：

```bash
.venv/bin/python -m phone_agent.web --port 8080   # http://127.0.0.1:8080
```

![控制台：一次真实运行的终态](assets/console-run.png)

## 界面

**顶栏**：任务输入（回车运行）· 状态药丸 · 实时 token 计数 · 配置抽屉开关。

**左栏（设备）**：实时画面（等比显示）+ 截图历史胶片条；点缩略图钉住历史帧，再点一次回到最新帧。

**主区页签**：

| 页签 | 内容 |
|---|---|
| 步骤 | 时间线：每步含状态节点（工具图标 + 状态色）、意图、工具/目标芯片、耗时；展开看参数与回执；点击步骤卡片可将左侧画面钉到该步截图 |
| 任务板 | TaskDoc 结构化渲染：目标、路线项（状态图标 + 证据）、最近步骤流程线 |
| 应用库 | App-KB 条目表（名称/包名/来源/成功次数/有效性）+ 手动 dream 整理 |
| 记忆 | 能力状态（生效/影子/关闭/待岗）、回想统计（评估数/Hit@1/污染率）、历次任务档案表 |
| 产出 | agent 写出的 HTML 文档列表（攻略/计划/报告）：沙箱预览、新窗口打开、删除（仅用户可操作） |

## 操控

| 操作 | 行为 |
|---|---|
| 停止 | 软停止：当前步完成后收尾，运行以 `takeover` 终局结束 |
| 人工中断 | `ask_user`/`take_over`/`hard` 档确认时弹出横幅，输入后继续 |
| 配置抽屉 | 每轮运行的覆盖配置（设备/模型/安全模式/预算/grounding/记忆开关）；只对下一轮运行生效，不写回 `.env` |

## 边界

控制台是可选观察层：不启动它，CLI 用法的全部机制不受影响。token 用量按角色分列（主模型/压缩/验收器/安全复核），与 token 预算同口径。
