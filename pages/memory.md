# 记忆与自进化

## 已落地：App-KB（本机应用事实库）

TaskWizard 不维护静态的"app 名→包名"表，而是**从设备学**：

```
run 启动时同步本机可启动应用（设备事实，按设备序列号隔离）
   ↓
模型启动成功一个叫法 ≠ 官方名的应用 → 自动沉淀 learned 别名
你明确纠正（"XX 就是 yy"）→ 记 user 别名（最高优先）
   ↓
下次 run：resolver 优先命中 learned/user 别名 + prompt 注入本机应用清单
```

- **存储**：`memory/app_kb/` 下 JSONL 事件日志（本源）+ `kb.json` 物化视图（可重建）；
- **隐式纠正**：中文叫法 launch 失败 → 模型换包名成功 → 自动记住映射（`PHONE_AGENT_IMPLICIT_ALIAS`，证据闭环：包名必须出现在当时失败回执的候选列表里）；
- **dream（整理工）**：run 之间合并事件、淘汰已卸载应用、衰减长期不用的条目（`--dream` 或 `PHONE_AGENT_DREAM=auto`）；
- **隐私**：只存应用名/包名/来源/计数，不存任何任务内容。

## 建设中：经验记忆与语义回想（RAG）

路线图上的下一步（设计已定，滚动落地中）：

1. **episode 记录**：每次 run 结束落一条结构化"任务档案"（目标/成败/步数/token/转折点/判决 + 时间维度），隐私白名单先行——只存骨架，不存密码、输入内容等敏感文本；
2. **语义回想（RAG shadow）**：sqlite-vec 本地向量索引 + MLX 本地嵌入模型（Qwen3-Embedding-0.6B）；新任务先查"以前有没有类似经历"——**影子模式只记录不注入**，用 run 的实际行为自动验证命中率；
3. **提炼与晋升**：dream v2 用 LLM 对比成功/失败档案提炼候选经验，Rule-of-3 + 人工确认后才晋升为正式经验；
4. **有界注入**：晋升的经验在相关任务开局进入上下文（上限 3+1 条 / 800 token），一键可撤销。

原则：**先记录、再影子、最后才动模型行为**——每一步都可回退。

## 设计红线

- 记忆只能经由**声明过的注入点**影响模型输入，永远碰不到 marks 解析、安全判定、finish 验收器；
- run 启动时对记忆拍快照，本 run 只读这代；新版本只对下一个 run 生效（热加载原则）；
- 一切可调：模型、阈值、保留窗口、开关档位全部走[配置](configuration.md)。
