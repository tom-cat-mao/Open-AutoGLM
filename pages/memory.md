# 记忆与自进化

## 第一层：App-KB（本机应用事实库）✅

TaskWizard 不维护静态"app 名→包名"表，而是**从设备学**：

```
run 启动时同步本机可启动应用（设备事实，按设备序列号隔离）
   ↓
启动成功一个叫法 ≠ 官方名的应用 → 沉淀 learned 别名
中文叫法失手 → 回执候选里的包名随后成功 → 隐式纠正记住映射
你明确纠正（"XX 就是 yy"）→ user 别名（最高优先）
   ↓
下次 run：resolver 优先命中 learned/user 别名 + prompt 注入本机应用清单
```

- 存储：`memory/app_kb/` 下 JSONL 事件日志（本源）+ `kb.json` 物化视图（可重建）；
- dream（整理工）：run 之间合并、淘汰已卸载应用、衰减长期不用条目（`--dream` 或 `PHONE_AGENT_DREAM=auto`）；
- 隐私：只存应用名/包名/来源/计数。

## 第二层：经验档案（episode）✅

每次 run 结束自动落一条结构化"任务档案"到 `memory/experience/`（JSONL 日志 + 物化视图）：

- 记录什么：目标（脱敏）、成败与终局原因、步数、分角色 token、警告次数、验收判决、涉及的 app、时间维度（时段/星期）、能力快照；
- **隐私白名单**：只存骨架——密码、输入内容、mark 文本等永不落盘；
- observe-only：**不改变模型任何行为**；
- dream 维护：超量归档为按类别的聚合成功率。

## 第三层：语义回想（RAG shadow）✅

- **索引**：sqlite-vec 本地向量库 + FTS5 关键词（`memory/vec.db`，可随时 `--rebuild-vec` 重建）；
- **嵌入模型**：本地 MLX 跑 Qwen3-Embedding-0.6B（`PHONE_AGENT_EMBED_MODEL` 可换），数据不出门；
- **召回**：硬过滤（本机设备/未撤销）→ 向量+关键词+时间衰减混合打分 → 低于阈值宁可静默；
- **shadow 模式**（默认）：新任务启动时只记录"会召回哪几条"，**绝不注入模型上下文**；run 结束后用实际启动的 app 自动对答案，累计命中率/误命中率（控制台「记忆」页可见）；
- 攒够数据、命中率达标后，才讨论翻 `on`（真注入）。
